# arabic-trend-factory.
Arabic Trend Factory هو مشروع ذكي لإنتاج المحتوى العربي آليًا، يراقب الترندات في TikTok وInstagram وYouTube، ويحلل المواضيع الرائجة لاختيار أفضل الأفكار، ثم يحولها إلى سيناريوهات ومقاطع فيديو قصيرة وجذابة يوميًا، تستهدف الجمهور السعودي والعربي، باستخدام أدوات مجانية قدر الإمكان، بهدف توفير الوقت وزيادة فرص الانتشار.
